Mail Web v0.4.0-alpha.13

- 首次配置遇到 SMTP 连接故障时，向导给出排查提示，修复后可重新授权并继续原配置。
- 更换 Stalwart 地址后，向导会清除旧凭据和预检结果并要求重新授权。
- 服务应用配置而短暂重启时，控制台自动重新读取页面与注册检查结果。
- Linux AMD64 和 ARM64 均提供离线包、独立 CLI、对应源码与 SHA-256 校验清单。

在控制台「版本管理」选择 `v0.4.0-alpha.13` 更新。[升级与恢复指南](https://github.com/reina0721/webmail/blob/v0.4.0-alpha.13/docs/cli.md)

Mail Web v0.4.0-alpha.21

- 管理控制台采用 Material Design 风格，更新了侧边栏、移动端导航和配置页布局。
- 站点设置按基础信息、品牌外观、SEO、Turnstile 和邮件默认策略分区。后台任务、健康诊断、自动发送队列与操作审计集中在运维页面。
- 更新邮件服务与域名、安装与修复以及版本管理页面的界面。
- Linux AMD64 和 ARM64 提供离线包、独立 CLI、源码及 SHA-256 校验清单。

Mail Web v0.4.0-alpha.22

- 邮件工作区和管理控制台共用一套 Material Design 基础控件和主题。可在外观设置或命令面板切换深浅模式及六套强调色。
- 更新认证、安装和管理页面的布局与交互。版本信息、CLI 命令和站点配置中的常用值支持一键复制。
- 为页面切换和控件反馈加入统一动效，并适配系统的减少动态效果设置。
- Linux AMD64 和 ARM64 提供离线包、独立 CLI、源码及 SHA-256 校验清单。

Mail Web v0.4.0-alpha.7

- 注册检查单独显示 Stalwart 的旧回调地址和 Webmail 的连接或认证问题，并提供对应的排查入口。
- 主地址的 HTTPS 回调通过后，可以从控制台更新本安装的 Stalwart 专用 Hook。切换失败时尝试恢复原地址。
- 检查按钮、检查结果和生成后的收信验证链接显示在页面上方。
- 修复完整回归中的 Node 测试加载，并让旧版 AMD64 Shell 安装夹具使用其支持的 Docker 镜像存储。

在控制台「版本管理」选择 `v0.4.0-alpha.7` 更新。[升级与恢复指南](https://github.com/reina0721/webmail/blob/v0.4.0-alpha.7/docs/cli.md)

Linux AMD64 和 ARM64 均提供离线包、独立 CLI、对应源码与 SHA-256 校验清单。

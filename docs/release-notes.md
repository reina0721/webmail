Mail Web v0.4.0-alpha.12

- 「注册与验证」在页首显示当前是否开放注册，以及人机与收信验证是否已经通过。
- 重新检查时显示本次检查结果，已经验证的站点可以按需生成复验链接。
- 部署指南与当前控制台的按钮一致，列出自动配置、收信验证和开放注册的完整步骤。
- Linux AMD64 和 ARM64 均提供离线包、独立 CLI、对应源码与 SHA-256 校验清单。

在控制台「版本管理」选择 `v0.4.0-alpha.12` 更新。[升级与恢复指南](https://github.com/reina0721/webmail/blob/v0.4.0-alpha.12/docs/cli.md)
